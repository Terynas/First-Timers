The *World of Warcraft* game client stores all of its configurations in [console](https://warcraft.wiki.gg/wiki/Console "Console") variables (**CVars**). These variables affect many aspects of the game such as the graphics, the sound system and the interface.

The value of a CVar can be queried with [GetCVar](https://warcraft.wiki.gg/wiki/API:GetCVar?action=edit&redlink=1 "API:GetCVar (page does not exist)"). The complete list of CVars is available from [C_Console.GetAllCommands](https://warcraft.wiki.gg/wiki/API:C_Console.GetAllCommands "API:C Console.GetAllCommands").

## Setting CVars

There are several ways of setting the console variables. The most commonly used CVars are tied to the [Interface window](https://warcraft.wiki.gg/wiki/Interface_window "Interface window") settings.

### SetCVar

AddOns and scripts can set CVars by calling [SetCVar](https://warcraft.wiki.gg/wiki/API:SetCVar?action=edit&redlink=1 "API:SetCVar (page does not exist)").

    /run SetCVar("scriptErrors", 1)

[![Note](/images/Icon-information-22x22.png?81245f)](https://warcraft.wiki.gg/wiki/File:Icon-information-22x22.png "Note")

**Note:** [Secure CVars](https://warcraft.wiki.gg/wiki/API_GetCVarInfo "API GetCVarInfo") 🛡️ cannot be set in combat and only with `SetCVar` instead of with `/console`.

### Console

With the `/console` slash command.

    /console scriptErrors 1

The `/console enable` command or launching the game with the `WoW.exe -console` argument will allow you to open the [Console window](https://warcraft.wiki.gg/wiki/Console "Console") in-game by pressing the `` ` `` or `~` key.

![Console variables 01.png](/images/thumb/Console_variables_01.png/928px-Console_variables_01.png?83919c)

### Config.wtf

The [Config.wtf](https://warcraft.wiki.gg/wiki/Config.wtf "Config.wtf") file stores settings mostly relevant to game startup, such as `gxMaximize` for the screen window size and `locale` for the language.

    World of Warcraft\_retail_\WTF\Config.wtf

The [config-cache.wtf](https://warcraft.wiki.gg/wiki/Config-cache.wtf "Config-cache.wtf") files are used for character and WoW account-specific settings. They are synchronized to the server if the [synchronizeConfig](https://warcraft.wiki.gg/wiki/CVar_synchronizeConfig "CVar synchronizeConfig") CVar is enabled (by default).

    World of Warcraft\_retail_\WTF\Account\<AccountName>\<Server>\<Character>\config-cache.wtf
    World of Warcraft\_retail_\WTF\Account\<AccountName>\config-cache.wtf

Config files can be manually edited while the game is not running; they would otherwise be overwritten on reloading or logging out.

## CVar Scope

Some CVars are character-specific or WoW account-wide, for example:

- When setting [nameplateMotion](https://warcraft.wiki.gg/wiki/CVar_nameplateMotion "CVar nameplateMotion"), it will only be changed for your current character.
- When setting [chatBubbles](https://warcraft.wiki.gg/wiki/CVar_chatBubbles "CVar chatBubbles"), it will not be changed for any other WoW accounts on your Blizzard account.

## Resetting CVars

Use [GetCVarDefault](https://warcraft.wiki.gg/wiki/API:GetCVarDefault?action=edit&redlink=1 "API:GetCVarDefault (page does not exist)") or the [cvar_default](https://warcraft.wiki.gg/wiki/CVar_cvar_default "CVar cvar default") command to reset a CVar, for example:

    /run SetCVar("autoSelfCast", GetCVarDefault("autoSelfCast"))

    /console cvar_default autoSelfCast

The [AdvancedInterfaceOptions](https://www.curseforge.com/wow/addons/advancedinterfaceoptions) addon can show which cvars were changed from the default:

[![](/images/thumb/AdvancedInterfaceOptions_cvar_browser.png/320px-AdvancedInterfaceOptions_cvar_browser.png?4cdc06)](https://warcraft.wiki.gg/wiki/File:AdvancedInterfaceOptions_cvar_browser.png)

[](https://warcraft.wiki.gg/wiki/File:AdvancedInterfaceOptions_cvar_browser.png "Enlarge")

AdvancedInterfaceOptions cvar browser

To reset the whole user interface:

    /console cvar_default

[![Red exclamation mark icon](/images/Icon-warning-22x22.png?61f799)](https://warcraft.wiki.gg/wiki/File:Icon-warning-22x22.png "Red exclamation mark icon")Changing a character or account-specific CVar cannot be undone or reverted by uninstalling, repairing the game or [deleting](https://us.battle.net/support/en/article/7549) the WTF folder as they will be synchronized from the server again.
