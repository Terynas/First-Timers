# Obsidian templates (copy into your vault)

These are **starters** for a human-curated WoW addon canon vault. They are not required if you use Hindsight only.

1. In Obsidian: Settings → Core plugins → Templates (on).
2. Copy `decision.md` and `quirk.md` into your vault’s template folder.
3. Keep notes short; link to git paths instead of pasting large Lua.
4. Optionally ingest important notes into Hindsight (`hindsight_ingest_document`) so coding agents see them without scanning the whole vault.

Full setup: [`../addon-dev/agent-memory-setup.md`](../addon-dev/agent-memory-setup.md).
