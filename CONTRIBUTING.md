# Contributing

**First Timers does not accept external code contributions.**

This learning library is maintained solely by [Terynas](https://github.com/Terynas). Pull requests, patches, and unsolicited code drops will be closed without merge.

## What you can do

- **Read and learn** from the guides, notes, and starter addon.
- **Report factual errors** via GitHub Issues if the issue tracker is open (wrong Interface number, broken link after a patch, etc.).
- **Build your own addons** using what you learn here — your addons are yours.

## What you must not do

- Open PRs expecting a merge
- Redistribute synced third-party trees from `sync.sh` as if they were this project’s code (they keep their upstream licenses and stay out of git)

## Maintainers

Follow [`AGENTS.md`](AGENTS.md) when editing this repo with coding tools.

- **Never push** to GitHub. Finish locally; the human runs `git -C "First Timers" push`.
- Never add `Co-authored-by` / `Generated-by` (or similar) trailers.
- Commit only as **Terynas**. Local hooks under `.githooks/` enforce author and message policy.
